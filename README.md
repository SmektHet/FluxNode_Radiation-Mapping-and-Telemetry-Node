# Overview

FluxNode is a compact embedded radiation monitoring system designed to detect, log, and visualize environmental radiation data in real time.

The system will use a Geiger-Müller tube combined with a custom-designed high-voltage power supply to detect radiation events. The project will also include:
- custom hardware
- embedded firmware
- wireless communication
- environmental sensing
- data visualization

FluxNode is designed as a portable and standalone monitoring platform that can transmit radiation data to a backend database and visualize the collected information using Grafana dashboards.

# Core Features

- ☢️ Radiation detection using a Geiger-Müller tube
- ⚡ Custom high-voltage power supply
- 🔋 Battery-powered operation
- 🔧 Custom PCB design
- 📦 Portable enclosure
- ⏱️ Configurable logging intervals
